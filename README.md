# Aplicación de Inteligencia de Negocios para el análisis y toma de decisiones en el transporte urbano de Tacna

## Problema

El transporte urbano de Tacna presenta dificultades relacionadas con la prestación, supervisión y fiscalización del servicio. En marzo de 2026, la Defensoría del Pueblo exhortó a la Municipalidad Provincial de Tacna a fortalecer la fiscalización del transporte urbano, señalando aspectos relacionados con rutas, recojo de pasajeros y horarios.

Además, durante 2026 se han presentado conflictos relacionados con el incremento de las tarifas del transporte urbano y el impacto de estos cambios sobre la población. También se ha señalado la necesidad de contar con información técnica sobre costos y operación para sustentar decisiones relacionadas con el servicio.

El problema que se busca abordar desde Inteligencia de Negocios es más concreto:

Existe dificultad para analizar de manera integrada la información relacionada con rutas, horarios, demanda, tarifas y cumplimiento del servicio, lo que limita la disponibilidad de información para tomar decisiones oportunas sobre el transporte urbano.

## Objetivo general

Desarrollar una aplicación de Inteligencia de Negocios que permita analizar información del transporte urbano de Tacna y generar indicadores para apoyar la toma de decisiones relacionadas con rutas, horarios, demanda y prestación del servicio.

## Objetivos específicos

- Recopilar y organizar información relacionada con rutas, horarios, vehículos, demanda y tarifas del transporte urbano.
- Diseñar un modelo de datos que permita integrar la información necesaria para el análisis.
- Identificar patrones de demanda según rutas, horarios y períodos.
- Definir indicadores de desempeño relacionados con el servicio de transporte.
- Implementar un dashboard que permita visualizar los principales indicadores.
- Generar información para la toma de decisiones, identificando rutas, horarios o zonas que requieran mayor atención.

## Funcionalidades de la aplicación

La solución puede desarrollarse como un dashboard en Power BI con indicadores como:

- Cantidad de vehículos por ruta.
- Demanda por zona.
- Demanda por horario.
- Demanda por día.
- Evolución de tarifas.
- Cumplimiento de rutas.
- Tiempo promedio de recorrido.
- Comparación entre empresas o rutas.
- Rutas con problemas o baja cobertura.

También se puede incluir un mapa de Tacna para visualizar las rutas de manera geográfica.
